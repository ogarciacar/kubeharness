# 13. Go library only, no CLI or schema

Date: 2026-11-02

## Status

Proposed. Recorded in the CONCEPT.md decision table as "Open design".

## Context

Avoid building an unused configuration language or second product.

## Decision

Only an initial, appropriately scoped **Go library** is assumed; CLI, YAML schema and plug-in SDK are *not* committed.

## Consequences

Not recorded when the decision was made.
